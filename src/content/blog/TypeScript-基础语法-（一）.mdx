## 1. 类型声明

```ts
// 变量: 类型
let name: string = 'Tom';
let age: number = 20;
```

## 2. TS 的基本类型

```ts
string
number
boolean
null
undefined
bigint
symbol

// 不指定类型，尽量少用
any
```

## 3. 类型推断

```ts
let name = 'Tom';
let age = 20;

// 不指定类型 TS 也能自动推断出变量类型
name: string
age: number 

// 所以 TS 中通常这么写代码
const name = 'Tom';
const age = 20;
```

## 4. 函数参数类型

```ts
function add(a: number, b: number): number {
    return a + b;
}
```

## 5. 可选参数

```ts
// ? 表示这个参数可以不传
// name?: string 等价于 name: string | undefined
function hello(name?: string) {

}
```

## 6. Union Type 联合类型

```ts
let value: string | number;

// 下面两种赋值都合法，其他类型的赋值不合法
value = 'value';
value = 123;
```

## 7. 数组

```ts
let names: string[] = ['Tome', 'Jerry'];

let names: Array<string> = ['Tome', 'Jerry'];

let numbers: number[] = [1, 2, 3];

let values: (string | number)[] = [
    "hello",
    123
];
```

## 8. Tuple 元组

```ts
let user: [string, number] = ['Tom', 20];
```
